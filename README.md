# ChatApplication

Real time chat application built using Spring Boot WebSocket and Thymeleaf.
This project demonstrates how to create a simple messaging system where multiple
users can connect and communicate instantly through a web interface.

## Features
- Real time messaging using WebSocket
- Simple and clean user interface with Thymeleaf
- Spring Boot backend for handling connections and messages
- Broadcast messages to all connected users

## Tech Stack
- Java
- Spring Boot
- WebSocket
- Thymeleaf
- HTML, CSS, Bootstrap

## Purpose
This project is built to understand real time communication in web applications
and to learn how Spring Boot handles WebSocket connections.

## How to Run
1. Clone the repository
2. Open in IntelliJ or any IDE
3. Run the Spring Boot application
4. Open a browser and go to localhost:8080
